# Retro Web App

A retro-themed web application built with nostalgic design elements and interactive features.

## Live Demo
[Visit the Retro App](https://rakib-gazi.github.io/retro/)



## Technologies Used
- **HTML**: For structuring the webpage.
- **CSS**: For styling and adding retro aesthetics.
- **JavaScript**: For adding interactivity.

## Features
- Retro-inspired UI design.
- Smooth animations and transitions.
- Fully responsive layout for mobile and desktop.
- Interactive elements for an engaging user experience.

## Dependencies
This project does not use any third-party libraries or frameworks, relying purely on:
- Vanilla HTML, CSS, and JavaScript.
